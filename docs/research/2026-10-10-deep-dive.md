## 2. SkillsBench thật nhưng dynamic, ngược static-only

- Tồn tại: `[2602.12670] SkillsBench` trên arXiv. (Owner: https://arxiv.org/abs/2602.12670 — fetch 200, title khớp)
- Method là paired execution có/không skill trong container + pytest verifier, v1 84 tasks/11 domains/7308 trajectories, +16pp. Dùng nó để biện minh cho regex static là misrepresent. (`docs/scientific_metrics.md:136` trích B1 cho SkillsBench sai ngữ cảnh.)

## 3. Context/security literature không validate regex scoring

- Lost in the Middle thật: arXiv:2307.03172, TACL 2024, U-curve (đầu/cuối tốt, giữa tệ). (Owner: https://arxiv.org/abs/2307.03172 — fetch 200, abstract khớp.) Nó là quan sát, không phải công thức `1-avg(|0.5-p|^2·w)`; code B3 (`packages/core/src/scorers/dimB.ts:40-66`) dùng window ±0.15 câu + decay tuyến tính — sai owner.
- OWASP LLM01 prompt injection tồn tại nhưng khẳng định không có prevention foolproof, phải defense-in-depth runtime. Regex phát hiện *nhắc tới* guardrail, không đo hiệu quả. (Owner: https://genai.owasp.org/llmrisk/llm01-prompt-injection/ — fetch 200)
- MCP Registry là metadata directory (`server.json`, reverse-DNS), wire là JSON-RPC 2.0, không định nghĩa quality score. (Owner: https://modelcontextprotocol.io/registry/about — fetch 200)

## 5. Công thức SkillGauge lệch owner

- A5 tính Reading Ease (`206.835-1.015·w/s-84.6·syl/w`, `packages/core/src/scorers/dimA.ts:83`) nhưng nhãn “Flesch-Kincaid” (FK Grade = `0.39·w/s+11.8·syl/w-15.59`); constants docs (`docs/scientific_metrics.md:77`: 70/15/0.025/0.8) khác code (`dimA.ts:86-87`: 67.5/17.5/0.02/0.2). Đếm âm tiết bằng vowel-group (`dimA.ts:77-81`) sai silent-e/code token. (Owner FK: https://en.wikipedia.org/wiki/Flesch%E2%80%93Kincaid_readability_tests — fetch 200)
- TTR thô length-biased; fix chuẩn là MATTR/MTLD, không phải nhân 1.3/1.4/1.5. Một từ “approval” ⇒ TTR=1 ⇒ H1≈1 (`packages/core/src/scorers/dimH.ts:7-11`). (Owner: https://en.wikipedia.org/wiki/Type%E2%80%93token_distinction — fetch 200)
- “Dependency distance” của repo là regex token-gap forward-only (`packages/core/src/scorers/scientificUtils.ts:55-85`), không phải parse-tree distance; cùng cặp if→manual dùng /24, /34, /44 (`dimH.ts:16,46,78`).
- Entropy trên tập ≤2 loại cap 1 bit rồi chia 4/3/2 ⇒ ≈0 thực tế (`dimH.ts:32-36,63-67,94-98`). Entropy ≠ quality.
- Goodhart: measure thành target thì mất hiệu lực; RLHF overoptimization theo đường cong Goodhart; static benchmark deterministic là Goodhart-vulnerable by construction. Keyword metrics là adversarial-Goodhart mẫu mực. (Owner: https://en.wikipedia.org/wiki/Goodhart%27s_law — fetch 200; Gao et al. ICML 2023; Manheim & Garrabrant via Stanford AIMS — đã dẫn ở file trước)
